# Security Policy

vskills runs on your machine: the installer writes into your home folder, and skills tell an AI agent which commands to run. Please report anything that could delete data, leak secrets or run unexpected commands.

## Reporting a vulnerability

Do not open a public issue. Use [private vulnerability reporting](https://github.com/vyvu99/vskills/security/advisories/new) and include the affected file, steps to reproduce and the impact.

## Supported versions

Only the latest commit on `main` receives fixes.
